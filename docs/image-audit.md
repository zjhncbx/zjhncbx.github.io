# 图片审计报告（image-audit.md）

> 项目：`zjhncbx/zjhncbx.github.io`（Astro 7 静态站点，GitHub Pages）
> 阶段：P1（图片性能与静态资源优化）
> 说明：本报告由批量脚本自动统计，基于 `public/wp-content/uploads` 下的全部图片，结合 `src/data/*.json`、`src/**/*.astro`、`public/**/*.css` 中的引用关系分析。**只读分析，未删除任何原图。**

## 五、优化处理结果

### 静态图片（JPEG/PNG）
| 分档 | 原体积 | 优化后（WebP 副本） | 节省 |
| --- | --- | --- | --- |
| 被引用 ≥100KB | 343 MB | 112 MB | **232 MB（67%）** |

### 动态 GIF
| 分档 | 原体积 | 优化后（动画 WebP 副本） | 节省 |
| --- | --- | --- | --- |
| 全部 GIF | 280 MB | 130 MB | **150 MB（53%）** |

> 优化策略：为每个目标图片生成**同名 `.webp` 副本**（`original.jpg` → `original.webp`），渲染层用 `<picture><source type="image/webp">` 优先加载 WebP，**原图与历史 URL 全部保留**作为不支持 WebP 浏览器的回退。未删除任何原图。

## 七、可复现工具

```bash
npm run images:audit     # 只读统计（不写文件）
npm run images:optimize  # 为被引用静态 jpg/png 生成 WebP 副本
npm run images:gif       # 为被引用动态 GIF 生成动画 WebP 副本
npm run images:report    # 前后对比报告
```

脚本：`scripts/optimize-images.mjs`。
